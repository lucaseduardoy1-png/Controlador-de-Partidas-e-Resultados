⚽ Controlador de Partidas e Resultados

Meu primeiro projeto desenvolvido em Python!

📌 Sobre o projeto

Este programa registra resultados de partidas de futebol e apresenta um relatório de desempenho de um time.

🚀 Funcionalidades

- Registro de gols feitos e sofridos.
- Contagem de vitórias, empates e derrotas.
- Cálculo do saldo total de gols.
- Relatório final das partidas.

🛠️ Tecnologias

- Python 3
- Pycharm (ambiente de aprendizado)

▶️ Como executar

Execute o arquivo "Controlador.py" em um ambiente Python 3 e informe os resultados das partidas.

📚 Objetivo

Praticar estruturas de repetição, condicionais, variáveis, contadores e acumuladores.
